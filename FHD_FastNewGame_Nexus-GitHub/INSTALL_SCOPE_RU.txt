Исходный README_RU.txt сохранён без изменений для проверки контрольных сумм:

горячего переключения. Глобальный манифест содержит Enabled=1.

XenoNative.ini воспроизводится без изменений, включая AutoRestartNativeMods=0
и исходные параметры BigGalaxy. Он относится ко всей установке загрузчика.
Эта сборка сохраняет оригинальный файл; автоматического объединения с чужими
настройками не выполняется.
